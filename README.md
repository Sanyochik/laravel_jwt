# Laravel CRM с JWT-аутентификацией

## Описание

Проект представляет собой небольшую CRM-систему, разработанную на **Laravel 13** с использованием **React** (Inertia.js) и **Tailwind CSS**. Реализована полноценная JWT-аутентификация (регистрация, логин, выход, обновление токена), а также CRUD-операции для двух сущностей: **Клиенты** и **Задачи**. Задачи привязаны к клиентам (необязательная связь) и имеют фильтрацию по клиенту, статусу, а также сортировку по различным полям.

---

## Основной функционал

### Аутентификация
- Регистрация нового пользователя.
- Вход с выдачей JWT-токена.
- Выход (инвалидация токена).
- Обновление токена (refresh).
- Получение данных текущего пользователя (маршрут `/api/me`).

### Клиенты
- Список всех клиентов (доступен всем авторизованным пользователям).
- Создание клиента.
- Редактирование и удаление клиента.
- Хранение клиентов в базе данных (таблица `clients`).

### Задачи
- Список задач с отображением названия, статуса и времени создания
- Создание задачи с выбором клиента из выпадающего списка.
- Редактирование и удаление задачи.
- **Фильтрация** по клиенту и по статусу.
- **Сортировка** по дате создания, названию (по возрастанию/убыванию).
- Задачи не привязаны к пользователю напрямую.

### Безопасность
- Все API-маршруты защищены middleware `auth:api`.
- На фронтенде используется перехватчик axios для автоматической подстановки токена в заголовок `Authorization`.
- Страницы (списки, формы) проверяют наличие токена в `localStorage` и перенаправляют на логин при его отсутствии.

### Интерфейс
- React-компоненты с использованием Inertia.js для маршрутизации.
- Стилизация с помощью Tailwind CSS.
- Адаптивный дизайн, таблицы с данными, формы с валидацией.

---

## Технологии

- **Backend**: Laravel 13, PHP 8.5, SQLite (или MySQL)
- **Frontend**: React 18, Inertia.js, Tailwind CSS, Axios
- **Аутентификация**: JWT (пакет `tymon/jwt-auth`)
- **Сборка**: Vite

## Установка и запуск

### Требования
- PHP >= 8.1
- Composer
- Node.js >= 18
- OpenServer (или другой веб-сервер с поддержкой PHP)

### Шаги
1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
```
2.Установите PHP-зависимости
```bash
composer install
```
3.Скопируйте .env.example в .env и настройте подключение к базе данных
```bash
cp .env.example .env
php artisan key:generate
4.Настройте JWT-аутентификацию:
```bash
composer require tymon/jwt-auth
php artisan vendor:publish --provider="Tymon\JWTAuth\Providers\LaravelServiceProvider"
php artisan jwt:secret
```
5.Выполните миграции:
```bash
php artisan migrate
```
6.Установите Node-зависимости и запустите Vite:
```bash
npm install
npm run dev
```
7.Запустите сервер (если используете OpenServer, настройте домен на папку public):
```bash
php artisan serve
```
8.Откройте сайт и пройдите регистрацию/вход

API-эндпоинты
Все эндпоинты защищены JWT-токеном и имеют префикс /api.

| Метод       | URL |Описание|
|-----------------|------------|------|
| POST       | /register    |Регистрация|
| POST            | /login |Вход|
| POST  | /logout      |Выход|
| POST    | /refresh |Обновление токена|
| GET     | /me |Данные текущего пользователя|
| GET     | /clients |Список клиентов|
| POST      | /clients|Создание клиента|
| PUT/PATH      | /clients/{id} |Обновление клиента|
| DELETE      | /clients/{id} |Удаление клиента|
| GET      | /tasks |Список задач (с фильтрацией и сортировкой)|
| POST      | /tasks |Создание задачи|
| PUT/PATCH      | /tasks/{id} |Обновление задачи|
| DELETE      | /tasks/{id} |Удаление задачи|

Параметры фильтрации для /tasks:

client_id – ID клиента (число)

status – pending, in_progress, completed

sort_by – created_at, title

sort_order – asc или desc
